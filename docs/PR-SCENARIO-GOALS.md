持续条件在每个新旬满足时累计；中断归零，跳过未检验的旬数不补记。同旬预演、提交、续写重试与读档均不多算。达成后沿用原奖励和分朝凭据，只发一次。达成条件、当前值与已保持旬数可在游戏内展开；登基页也可提前查看。

专属目标属于所选预设的第一位皇帝。继位时照原规则封存先帝目标、为新帝另选通用宏愿，不让后继之君继承崇祯或康熙本人的心事。预设仅为游戏开局，目标为玩法设计，不主张逐项复刻其史实心志或强制历史结局。
