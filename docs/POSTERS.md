# 御极 · 双版本海报

- [扫码版](../promo/yuji-poster-qr.png)
- [无二维码版](../promo/yuji-poster-no-qr.png)
- [独立二维码](../promo/game-qr.png)

两张均为1024×1536 PNG，同一套「夜御案」视觉。呈现御案批折、朝堂、边疆与皇嗣等真实游戏内容；不含虚构玩家数量、联机玩法或奖项。无二维码版没有网址、二维码或扫码引导。

使用内置imagegen先生成无二维码版，再以该图和真实二维码为参照制作扫码版。二维码目标是 https://lynch715.github.io/yuji-emperor/ ，由qrcode库生成；对最终海报以zxing-cpp解码，1024 / 768 / 512三种宽度均得到同一目标，无二维码版三种尺寸均未检出条码。属于软件解码验收，未冒称实体手机扫码测试。[完整解码记录](../promo/qr-verification.json)。

设计提示：2:3竖版；深色御案、朱砂批注、宣纸、暗金、宫灯；皇帝背影批阅奏折，前殿朝臣、远处边疆烽燧；醒目中文「御极」「一旬三时，落笔天下」，三行实际玩法「上朝批折·任贤治吏 / 钱粮民生·边疆征战 / 后宫皇嗣·一朝本纪」。不加网络地址或代码框。扫码版仅在右下方增添真实二维码和「扫码入局」，其余构图文字保持同系列。
