# 新增七剧本 · 重要人物专属像补充批

## 范围与实施前说明

玩家在PR #10发布后要求为七个新增剧本的皇帝、太后等重要人物补专属像。本批覆盖24位人物，另加6张皇帝老年续玩像，共30个肖像档位：新生成29个WebP，魏忠贤复用已验收的本人专属像。其他人物继续使用现有同朝代池图。分支`codex/important-portraits`，基线main `d61ddd3`；完成后草稿PR供验收，不合并、不发布。

- ART-SPEC原377张原画／390个WebP是已完成的原三期范围。本批由玩家明确追加，新增29张后为419个WebP；先在本PR记录范围扩展，不以原总数阻止新增。单张规格、画风、构图和缺图退回沿用原规范。
- 七位皇帝均画开局年龄。六位开局未满40岁的皇帝另有本人老年像；唐玄宗开局70岁，仅画一张老年开局像，同时映射base和old，避免重复画同龄脸。老年续玩像是游戏里的假设延寿外观，不声称人物历史上活到该年龄。
- 两位太后为董太后、孙太后。董太后史书未记生年，本批约50岁是美术估龄；孙太后约50岁。两人均明确女性，按本朝后妃冠服绘制。
- 后妃8位：宋皇后、何贵人、郑皇后、张嫣、钱皇后、杨玉环、朱皇后、钮祜禄皇后。何氏按开局贵人用朴素单簪，张嫣按剧本15岁少女画，不提前老化或画成成熟妇人。
- 核心臣子7位：张让、蔡京、魏忠贤、于谦、安禄山、李纲、和珅。魏忠贤53岁与既有崇祯剧本59岁属于相邻年龄，复用本人已验收专属，保持身份。其余六人单张新画。
- 只追加美术清单及取图验收，不改核心数值、剧本、事件、存档v26或现有390个WebP。每个专属像单张生成；每次传一期完整四图板和所属朝代四张定调图板，老年像另传本人青年像。
- 原始PNG放本机忽略目录`art-source/important/`，仅裁切、等比缩放和转400×500／q75 WebP；不靠修脸、调色或拼贴补画解决不合格稿。眼位36–40%，完整冠顶10–14%；每剧本重拼44px条检查撞脸。

## 史料与人物依据

年龄、位分、性格及秘密以当前`scenarios.js`与`extra-scenarios.js`为直接游戏依据。具体脸型、痣、肤色等属于美术设计，不冒称有史料记载；不模仿演员或影视形象。

- [《后汉书·皇后纪下》](https://zh.wikisource.org/wiki/後漢書/卷10下)：董太后、宋皇后、何氏关系；不把178年的何贵人提前画成皇后。
- [《宋史·徽宗四》](https://zh.wikisource.org/wiki/宋史/卷022)、[后妃传](https://zh.wikisource.org/wiki/宋史/卷243)：徽宗、郑氏及开局朝局。宋冠服沿用已确认长直幞脚、赭黄团龙、花钗冠与珍珠妆。
- [《明史·英宗前纪》](https://zh.wikisource.org/wiki/明史/卷10)、[后妃传](https://zh.wikisource.org/wiki/明史/卷113)、[熹宗本纪](https://zh.wikisource.org/wiki/明史/卷22)：英宗、孙太后、钱氏、熹宗和张嫣的身份与关系。
- [《旧唐书·玄宗下》](https://zh.wikisource.org/wiki/舊唐書/卷9)：天宝末年的玄宗与安禄山局势；唐制软脚幞头、圆领袍、后妃高髻花钿沿用已确认做法。
- [《清史稿·仁宗本纪》](https://zh.wikisource.org/wiki/清史稿/卷16)：嘉庆亲政与和珅案；清帝吉服冠、后妃女式钿子，均沿用已确认做法。
