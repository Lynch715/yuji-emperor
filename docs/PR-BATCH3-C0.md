## 规则与 DESIGN 差异的理由

1. 外交方向压力取平均：`0.9 + clamp((power−troops×readiness/100/500)/250,−0.15,0.15) − (attitude−50)/250 − treatyReduction`，婚盟 / 朝贡时 treatyReduction=1.05，其余 0。无绑定外邦时压力为 0。相较审计 B8 的除数 50 / 25 和盟约减半，缩小实力 / 态度增量并给正式盟约固定减量，是本次明确指定的 C0 校准；中性需月增 0.8–1.0、盟约允许下降。边患满 100 入寇、入寇后 45 及原事件成本保持。
2. DESIGN 规定亡国触发为“京城被攻破或民变攻入”，没有要求每旬 12% 突然亡国。按本次指令改为低民心低国库连续 9 旬警报、18 旬上限；急报截止第 18 个连续危机旬，超期才判未处置。任一指标恢复即解除，已处置但仍困顿不清除持续危机。复用既有线程字段，没有新增状态结构，存档维持 v5；未重算旧待续预演。
3. 三项急报的具体成本为开仓：粮 −30 / 民心 +6；调兵：国库 −8 / 民心 +3 / 皇威 −2；罪己诏：皇威 −6 / 圣德 +2 / 民心 +4。DESIGN 未定这些选项的具体数值；以原有钱粮和国势单位提供三种不同资源取舍，均通过核心效果包记账。选项一次处置并不保证脱离危机，不授予免亡国标记。
4. 模拟策略仍固定八分支、上朝最多三本、批折最多六本、合法冷却备选和摄政限制；本次减赋随机指定单州，批折均匀抽取可负担选项，各资源按负支出累计、国库保留 8 万两。正收益不预借给后续选项，没有可负担选项便跳过。策略的目标 / 选项抽样改变了 RNG 消耗，因此与批次 2 历史指标不能做同轨迹因果比较。四种子使用同一算法，没有按种子分支。
