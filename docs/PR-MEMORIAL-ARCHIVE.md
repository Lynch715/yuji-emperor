# 御批档案与分享图片

玩家希望回看自己批过的奏折，并把朱批做成图片分享。本次新增「御批档案」，入口位于奏报匣的完整列表和史馆，手机由底部「奏报」进入。

- 起驾正式提交后，为每次亲批保留奏折标题、上奏人、类型、原文、具体处置、后果说明、朱批、当时皇帝与纪年。留中、再议、只作朱批同样留底；同折再次批阅另留一份，可对照前后批示。仅拟批、失败的续写和重复提交不新增记录。
- 新记录不包含权臣、摄政或内阁委政的代批。内阁委政排程增加展示元数据标记，不参与任何数值判定。
- 档案随起居注章节及原有IndexedDB分卷保存，沿用完整JSON导入导出，不在主档另存一份不断增长的全文副本。历代皇帝的亲批保留当时署名。查看、筛选和生成图片不写游戏进度。
- 支持关键词搜索、类型筛选、只看有朱批及每页20份记录。正文和朱批原样安全转义；返回列表保留筛选与页码。
- 分享图为1080px宽PNG，米色纸笺、宋体正文、红色批示及手写朱批；按全文高度排版，长内容自动分图，每图高度不超过7600px，处理中文避头尾标点。可预览、保存，浏览器支持文件分享时显示系统分享按钮，不自动发布到社交平台。

## 兼容与限制

存档版本升v14，新章节增加可选`memorialReviews`。旧章节未留存的字段按空档案理解，在读取展示时从现存起居注提取旧折摘录，不原地改写已封存分卷，不改旧待续。旧记录不能还原未保存的原文、上奏人或皇帝署名，界面明确提示缺失，不用新模板补写。旧版委政与亲批若未作区分，只能按旧起居注留下的处置显示摘录。

历史分卷在校验和通过后再做完整存档结构检查；结构损坏仍进入只读保护，保留原始副本。原有回合幂等、预演时序、随机数和A1–A14均不变。七路径预演仅将v14版本标记还原为13，即与原v13政策哈希完全一致；不更新政策数值基线。

Canvas及浏览器分享API均为原生功能，无新增依赖或外部上传。图片只取选中的游戏记录，不包含接口配置、密钥或其他存档。字体未加载时使用本机中文字体。系统分享入口出现已验证，未向任何社交账号发布；实体手机分享面板未实测。

## 验证

- 新增9项测试：只在提交归档 / 幂等 / 原文快照、留中再议多次留底、逐本及旧式朱批 / 代批排除、v13待续与旧摘录、跨历史分卷 / 两槽隔离 / JSON全本、近期损坏保护、分卷结构损坏保护、搜索分页与转义、图片全文 / 长标题 / 中文标点 / 长文分图。
- 全套379项测试；200年、7,200旬无模型模拟。模拟的国势波动、粮储峰值、首次亡国时序与改造前一致，档案不影响数值。
- 应用内浏览器：旧v13试读继续亲批并归档、刷新后原文与朱批保留、旧录恢复、搜索及筛选、返回筛选保持；桌面和360px布局无横向滚动，控制台无错误或警告。
- 实际下载1080×1446 PNG并逐图查看，正文、选项、朱批与纪年完整，预览及保存按钮可用。超长内容分图通过排版测试，未使用真实模型API。
- 单文件约563KB，构建预算由550KB调至580KB，图标60KB预算不变。
