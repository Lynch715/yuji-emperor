# 自拟情节留下个人往事和实际的人情变化

此前自拟情节只有全文与公共事实摘要，御前面谈没有读取个人经历，妃嫔自然互动、NPC之间的关系与续写后果没有统一接通。现在人物记得与自己有关的相处，往事传入后续召见、新场景和续写；有分量的互动还会改变实际好感、外邦态度或双方人物关系。

例如安慰陆令仪如愿时好感增加2；调解她与沈清蘅时，双方原本50的关系各增4。好感较高时沿用原递减。羞辱不会因为“想做就成”变成讨人喜欢。关系沿用既有宫闱互动图，并为未来同场检定提供最多±8修正。普通召见闲聊依旧不掷骰、不刷好感。

## 规则与存档

`social-rules.js` 集中列出陪伴、安慰、道歉、维护、羞辱、欺瞒、调解、争执、合作的成功、部分成功及失败后果。意图模型只归类现有参与者与行为，`core/social.js` 采用本场原有自由度裁决写入数值、实际流水与结果；不增加第二次社交掷骰、不增加模型调用。试读使用保守的本地分类，指代不明不随意绑定。

同一场同类型、同对象相处只生效一次；原章与续写合用A9每人5、全章10的好感额度，包括原有赏罚与模型反应。修正续写中原章模型反应重复占用额度的计数问题。调解等双方关系不是对皇帝的好感，不冒记成赏罚。对现有默认50的关系，审计按真实50起算，不产生虚假的+54流水。

`core/memory.js` 将实际参加者的经历写入个人原有 `memory`。模型可从已经校验的正文逐字引用一条完整原句作为记忆证据，须为在场者目睹或听见的事；虚构摘句、已被断言删去的句子、心声与缺席者建议不采纳。没有摘句也会按实际结果和可公开正文形成基础记忆。受骗成功的当事人只记得听到的解释，不会直接获知欺瞒意图。

每人近期16段逐条保留，日常旧事按类型与对象合并为首尾摘要；实质行动与当面承诺逐件留摘要，全文始终在史馆原章。请求按重要往事和近期经历选取最多8条，避免逐次发送全库。模型得到的是参考记忆，是否自然提及及文学质量仍取决于玩家所接模型；不承诺每段对白都会复述旧事，也没有把承诺另建成自动任务或强制兑现机制。

存档升v19，复用 `memory`、`relations`、好感和外邦态度，皇嗣对在位皇帝的亲近也用关系图保存。新增格式与场景的相处结果均为可选，补充结构校验；旧档无字段表示尚未记录。旧v18场景从仍可读的旧正文按需补读记忆，再进行新场景时完整回填；不重算好感、不动原骰、旧待续或事务指纹。分卷未加载或恢复副本不误标完整回填，缺失的历史原文不能凭空恢复。现有双通道保存、导出和档案保留个人记忆与关系。
