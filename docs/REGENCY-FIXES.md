# 幼帝摄政三项修复验收

日期：2026-11-06（America/Los_Angeles）。基线：`main` / `093eaad1fc02d12fd42441cc42fe71065929685f`。分支：`codex/regency-fixes`。在独立 Git 工作区开发，未动原工作区的美术与文档改动。只做本地提交，不合并 main，不推送、不部署，等待玩家测试。

## 修复与入口检查

1. 奏报匣新增行动时使用 `memorialEntryKind()`，通过 `actionAvailability(s,'上朝')` 决定能否进入上朝；摄政、御驾在外、朝间占用等情况均回到批折。时辰仍取空闲朝／午。已拟批奏折和原日程编辑沿用原行动；左侧行动卡经可用性禁用，序章一直使用批折。检查 `src/ui` 所有 `memorialDialog()` 调用，没有第二个按空朝间硬选上朝的新批入口。批折“问责”按钮未修改。
2. `scenarios.js` 仁宗剧本增加 `dowagerFaction: 'f2'`，落入状态的 `dowagerFaction`。太后择摄政与实际代批共用 `dowagerPerson()`，有母妃时用其派系，否则用剧本派系。核对七剧本，仅仁宗指定 `regent: 'dowager'`；万历为张居正、康熙为索尼。继位时更新为新帝母族，不把刘氏派系传给后继皇帝。
3. `regency.growth` 保存上次结算的整数年龄与教养。`advanceRegency()` 只叠加 `aptitude × Δmin(1,age/16) + Δeducation/10`，不再整体覆盖五才。经筵原有文采 `+0.2` 可保留。历史幼帝新增成长通过 `growTalent()` 与批折、经筵共用每年每项 `+3`；超出额度的部分当旬消耗，不留待次年补领。满16岁仍先结增量，再撤摄政、记亲政和大婚，不重置人才数值。

## 设计文字调整／PR 说明

`DESIGN.md` 的“五才”一行补充了两种既存开局的区别。历史幼帝已有手工设定的五才，不应被统一成熟公式覆盖，未来成长共用年度 `+3`；继位生成的婴幼帝原本由 `资质×年龄/16 + 教养/10` 决定自然成熟，仍保留其初值与自然成熟幅度，再额外保留主动历练。否则将从0长大的幼帝一并按年封顶，会使16岁自然成熟上限由接近资质骤降至48，改变本次要求尽量保留的继位路径。自然成熟不占该路径的主动历练额度；规则已明确写回设计，并用0、8、15岁继位回归核验。

年龄仍按原规则整岁结算，年度额度仍由原年结重置。未更改“天圣亲政”的政略70等目标：修复后纯歇息亲政政略仍可达72，这是保留公式并遵守每年+3后的结果；本次不另外调整心事门槛。

## 存档兼容

- 存档由 v23 升到 v24；新增 `dowagerFaction`（普通王朝为空）及摄政中的 `regency.growth`。
