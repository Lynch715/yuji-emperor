## 数值与 DESIGN.md / 原审计公式的差异

- 按本次最新指令覆盖审计 C2 的人口乘 0.15 和霉变 10%：季度新粮为 `季度军粮 × 1.2 × Σ(pop × (1−disaster/100))/Σpop`；超出三年仓容的部分年霉变 30%。不扩大仓容，不对入仓加硬截断。
- 新局初始粮储从 650 调到 240 万石，约 29 个月初始军粮，避免新局本身就超过仓容的 1.2 倍。迁移不追减旧库存；真实 v6 预演的 650 万石原样提交。
- 仓储 / 漕运 / 运粮检核请求的准奏支用 0.6 万石役粮，普通案牍仍只给 0.1 吏治；空仓改呈粮缺核报、仍明确申请核验役粮，不请求搬运不存在的粮。银粮开支都由 core 记账。
- v7 是硬性原则要求的结构升级：逐本决定及可选 `remarkKind`。旧 pending 的骰子、钱粮、RNG 和旧规则已确定的好感结果不重算；新规则只用于新预演。
- 题材中长朝字表耗尽的名字采用同档字组合，避免数字后缀与重复；正常分档首选字仍来自字表。

## 模拟策略口径

仍用四个固定种子与同一套四类策略，八分支、上朝最多 3 本、批折最多 6 本、急件顺序、选项均匀抽样、国库留 8 万两、减赋随机一州均保留。C2 让粮不再无限时，原“下旨”分支可能请求付不起粮的赈灾而抛错；现在沿原轮转顺序同时检查合法性与钱粮，选不到可负担圣旨就不安排该槽。此检查同时作用于乱批和尽职，没有按种子分支，也不改为无限借粮。

粮储有限增长的 balance 上界中的霉变率和新局库存相应从 `0.1 / 650` 更新为 `0.3 / 240`，上界收紧；其余门槛原样保留。没有恢复已删除的亡国率豁免字段。
