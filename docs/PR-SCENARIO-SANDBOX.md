## 实施前记录的设计变化

- 玩家明确授权彻底放开free档，故覆盖DESIGN旧版「钱粮、职权、任官资格、年代及模板仍限原规则」的要求。free资源不足时由核心补足并单独记账，玩家明确指定的数量、结果不再以原余额、每人5点好感或每章10点为由截去。模型仍须交给核心结构化指令，不能靠正文暗改状态。
- 通用指令只编辑游戏世界；存档版本、随机种子、事务回执和旧预演由引擎维护。指令按原文逐条拆分、验证、一次提交，复合指令可创建对象后继续引用，不允许把不能解析的指令伪装成已经完成。
- 新增存档结构升v26，迁移只补默认字段；已冻结的旧预演保持原样，提交时升级结果，不重掷、不重算。旧局不追补已经过时的固定事件；后继皇帝不重演首位皇帝的事件。
- 页面体积服从本次内容扩展，不再围绕旧页面预算压缩或删减玩法。保留单文件构建和独立WebP，不增加构建依赖。现有390个WebP继续复用。

## 言出法随的实际操作

- 设置与增加：国库、内帑、粮储、五才、健康、心情、好感、忠诚、军队、州郡等实际属性；中文亿万与两／石按游戏单位换算。钱粮不足时补足所需并记录来源。
- 人物与官职：创建人物、任免、自创官职、下狱、死亡与复生；复合御旨可先创建后任命，不要求年龄资历。各类新人物继续使用已有美术池。
- 国势：创建州郡、国家、派系，改写战果和邦交；已有战役结算并撤回失效军报。已知科技补足前置，自创新技术进入世界对象；即时工程竣工会真正建成产业、实施赋税或赈济效果，重发不重复结算。
- 世界对象与制度：自创事物有名称、说明和数值属性；可设每旬操作、修改或撤销，出现在国势全览与内库，随存档及后续叙事上下文保存。每旬制度依实际回合只运行一次，切回一般／严格暂停运行。
- 模型只将原文翻译成结构化操作，不能执行代码、改种子或替代事务。复合操作整体校验，一项失败整条不生效。复杂自由文本仍依赖连接模型进行理解；本地试读只支持常用句式，未完整解析时明确提示，不声称成功。本轮没有使用真实模型API或用户密钥；解析及叙事上下文采用确定性测试，浏览器测试使用试读。

浏览器实际执行的复合御旨：

> 国库设为一亿两；全体官员忠诚设为100；创建官员张三；任命张三为工业部长；张三年龄设为12；每旬国库增加一百万两

执行后张三为12岁并实际占据工业部长职位，开局官员忠诚为100。国库先设为10,000万两，每旬制度加100万两，叠加本旬其他政务后的余额为10,091万两；并未忽略其他支出。刷新后第2旬、人物和制度保持。
