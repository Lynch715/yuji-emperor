# 手机界面、文字与图标审计

日期：2026-11-01。运行源码只改 src/ui，附带测试、审计材料和重新构建的 index.html；程序版本仍为0.9.1，存档仍为v4。核心 / LLM / 存储23个源码文件与施工前哈希一致。用户原4173页面及其卷位未操作，浏览器验收在独立4177来源进行。

## 发现与修复

| 项目 | 审计发现 | 本次处理 |
|---|---|---|
| 竖屏按钮与表单 | 360px 下现有控件有效触控区均至少44px，输入字号16px；未发现整页横向溢出 | 保留既有尺寸和表单值，不为通过检查伪造问题 |
| 横屏 / 短视口 | 844×390时正文被压至36px，日程下方操作与正文难以到达 | 600px以下的手机视口改为整体案面滚动，正文至少260px；实际滚动到起驾及正文区复验 |
| 缩放 | 原 viewport 没有限制页面缩放 | viewport加入maximum-scale=1 / user-scalable=no；CSS只允许横纵平移；取消双指touchstart / touchmove及Safari gesturestart / gesturechange的默认缩放。单指滚动与文本选择保留 |
| 安全区与输入 | 原底栏安全区会占用固定栏内空间，弹窗未跟随visualViewport | 顶栏 / 左右 / 底栏留安全区，底栏高度额外包含安全区；可视视口变化时重算高度及弹窗位置，短视口输入时关闭按钮可见 |
| 弹窗换层 | 旧弹窗close回调可能在新弹窗已打开时回退焦点 | 仅在所有模态关闭后解锁背景并恢复焦点；打开弹窗时锁背景，关闭后解除 |
| 手机弹窗首屏 | 文书 / 人物预览较高，挤占表单 | 收紧预览卡的字号与段间距，保留原字段和功能；长弹窗仍可滚动至底部 |
| 开发口吻与冗长提示 | 开篇、登基、存档、面谈等处出现引擎、预演、参考实现、样张等说明 | 改为短句，键盘提示只在桌面显示；设置页保留必要的服务商 / 型号 / 密钥字段和存档保护提示 |
| 连接测试 | 流式阶段会将原始JSON片段展示到设置页 | 改为等待提示，仅显示最终连接结果 |
| 默认章节标题 | 试读标题带“诸事已据实落账” | 仅在显示层去掉这句固定尾注，正文、历史存档与导出原文均不改写 |

没有新增或改写引擎规则、默认模型、请求格式、存档结构与效果包。两项上一轮引擎待办仍留在 NEXT-STAGE.md。

## 浏览器实测

使用 Codex In-app Browser，经localhost提供页面，没有改用其他浏览器操作。

- 26个实际界面记录：主界面、登基、上朝 / 批折、其他9类可用行动、六殿、行动 / 奏报 / 殿阁 / 起居注 / 菜单 / 国势抽屉及设置。主体在360px，补查登基为390px；均无整页 / 弹窗横向溢出，button / select / textarea / summary及复选框对应label有效目标均不小于44px。亲征因无战事而禁用，未将其表单或尚未出现的择师、继位等状态列为已验收。
- 五档视口 **360×640、390×844、768×1024、844×390、390×480**，共25个主界面 / 批折 / 下旨及弹窗末端记录，均无横向溢出或小于44px的有效目标。横屏正文260px且案面可滚；390×480短视口正文305px且案面可滚。
- 实际聚焦御旨输入框后，关闭按钮仍可见；45次Tab不越出弹窗；换层后背景保持锁定，弹窗滚动不带动背景，Esc退出后恢复。手机单指滚动、下拉选择、选项与下一本均实走。
- 固定种子七条路径（上朝三本 / 批折六本 / 发部议 / 留中 / 问责 / 朱批 / 廷议）再次实际点击，完整行动、原状态和整份预演哈希均与阶段9旧界面记录一致。
