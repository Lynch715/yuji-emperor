## 研究与产业规则

实现18项科技、五条线路。完整费用、最短月数、前置、主持衙门与效果见 `src/core/tech-rules.js`。

| 线路 | 研究顺序 |
| --- | --- |
| 农政 | 精耕细作 → 占城稻推广 → 番薯玉米 → 农具范式 |
| 水利 | 水车改良 → 束水攻沙 → 漕运疏浚 → 水利图籍 |
| 工商 | 织造改良 → 匠籍松绑 → 银钱折纳 → 行会则例 |
| 盐铁 | 晒盐法 → 冶铁鼓风 → 新式火器 → 炉温准式 |
| 海贸 | 宝船图式 → 市舶则例；均须先完成开海 |

月经费上限20万两；先结固定俸饷、宫用、赈抚和现有费用，再按国库余额缩减研究拨款。主持必须在朝任职，在世且未被下狱或致仕。

```text
月进度 = 实拨经费 × (0.6 + 主持政务能力×0.008)
         × (0.6 + 吏治×0.004)
         × (清议当权且不满时0.8，否则1)
```

“当权且不满”取名称含清流／清议／儒生／台谏、势力≥60、态度<40。条目费用是基准研究量，实际累计拨款受主持与吏治影响。未达进度时，停拨、缺钱或主持失效均暂停；进度已满后等待最短月数，不再重复支银。重申、更换主持不重置进度；不能用新方向覆盖旧课题。完成效果只结一次，生成突破 note 和工部报捷折。

| --- | --- | ---: | --- |

这里的季产是基数，实际产出按灾情、民心、吏治及技艺修正。漕运全国粮运增益封顶18%，市舶司产业互市增益封顶50%；再叠海贸科技。建造和升级都走 projects，预付钱粮、等待月结办理，完成后才形成产业；重申在建工程不重复扣钱。

文档未指定的细节，本批固定为：每州3槽（在建也占槽）、同类最高3级；升级支付相同基价，工期为基础月数加目标等级−1。州郡名册相邻两项作为漕运扩散邻州。民变、当季民变留痕、灾情≥80、民心<15或当季维护费不足时停产；维护费按现银实付，不凭空产出。条件恢复后自动复产。

每季繁荣按文档公式增长，灾乱追加衰退，限制0–100；税收乘 `1+繁荣/100`，粮产按人口加权乘 `1+繁荣/200`，年结人口增长率增加 `繁荣×0.00002`。当季繁荣增长用于后续季度收益，不追补已经结算的钱粮。
