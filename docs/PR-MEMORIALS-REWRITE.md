# 奏折多样性、详细奏文与一次改写

后续：本文件记录的统一费用、第三本固定役粮已由用户追加要求下的[独立政策取舍](PR-MEMORIAL-CHOICES.md)替代；95题轮换、详细奏文与一次改写机制沿用。

## 奏折

重复来自固定抽取顺序：前几本总是钱粮、政务、仓储，其他组往往抽不到；试读还会把各折正文覆盖成同一套话。本次按用户要求改为全类型轮换。

- 95个模板，25类事务；包括刑狱、农桑、商贸、民生、工务、文教、医药、内廷与战事。具体争议包括借书与损毁责任、轮灌与旧契、夜市与巡夜、便桥与水路、军眷家书与军报优先等。
- 从符合当前国势的类型中选近期最少出现者，再选近期最少出现的题目。同批尽量不同类型，同题未批不重发。有灾州各自有请赈，同州未批不重报；无灾不编请赈，无战事不编行营奏折，空仓不请求翻晾旧谷。
- 保留每旬3–6本及原有省份抽签，不增加游戏随机数流中的抽签。题材用 `core/rng.js` 派生的独立内容种子，可复现。
- 常规准奏仍为国库−2万两 / 吏治+0.1，驳回仍为皇威+0.2；赈灾保留原效果。原每批差役口粮0.6万石预算保留，题材可变，在请求中说明外差口粮，不靠改变经济收益制造新鲜感。
- 依实际主管衙门选现有上奏官员；不创造有姓名的人物。各折提供与本题相符的批准 / 暂缓办法，仍使用现有选项ID与纯引擎效果包。
- 正文分三段：来由、利害与顾虑、请旨。现代文试读95个样本162–192字；其他文风试读143–173字。模型生成明确要求每本160–260字，提供实际请求与选项，避免靠寒暄凑字。已收旧折不重写。

## 第四步

`validateTurn` 增加纯诊断回调，保留原删除规则。`llm/rewrite.js` 收集正文、摘要、伏笔、奏折文字与风闻中的违规句及原因，只发送这些句子和本旬结果。模型仅返回 `rewrites:[{id,text}]`；未知ID、额外章节及数值效果一律不采用，未违规句不能被覆盖。改写后重新执行全部原断言，仍违规时采用原删句 / 补足逻辑。

A8替词、A14含蓄化不触发额外请求，原来如何处理现在仍如何处理。原结构化人物反应、数值截断、提交幂等、过期预演保护不变。

改写前先将 `turnBudget.rewriteAttempted=true` 保存，保存失败不发请求；关闭页面、重新读档或手动续写都复用此标记。本章一次指一次尝试，接口失败或JSON错误也不自动请求第二次。改写占用原四次 / 240秒正文额度，不显示改写JSON流。若改写后整章仍为空，可以在剩余额度中重试正文，但不再改写。
