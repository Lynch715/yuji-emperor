# 召见与奏折体验调整

玩家只能聊三五轮、每旬只能召见一人，上朝和再议也有孤立的次数限制，交谈还会刷好感。按玩家确认的审计建议，三档统一取消这些硬上限，以真实精力、钱粮、职权、期限和重复办理保护控制实际代价。

## 行为

- 普通聊天无限轮，不掷骰、不涨好感，也不生成反复的“拟议”口谕。说服、威吓、试探及实质动作仍裁决，同旬反复施压沿用结果；相同结构化请求不重新掷骰或扣款，明确再拨、追加才另办。重复确认已办拨款不重复占用职权额度。
- 午间可先后召见多人，每个不同人物耗1精力，同人续谈不增加。保留已经生效的全部召见，不能靠撤日程抹去实际行动。上朝不限本数，前3本耗2，每多3本加1。再议不限次数，但期限不再顺延，逾期代价保留。
- 同类旨意与同国互市取消冷却。同一在途事项默认重申，不建重复项目、不再收钱；可追加一份钱粮督办，缩短工期、改善执行，同项目仍只竣结一次。互市成功替换单一旧约，失败保留旧约，季度收益不叠加。
- 两库拨转、妃嫔赏赐取消固定金额上限，按余额截断；转账也受收款账户容量约束。赏赐以同旬累计金额计算边际递减，拆单不多得好感。
- 保留大选周期、位分名额及原成人条件，新增平日日常举荐渠道：内帑3万两举荐一位18岁以上候选，随后另排午间留牌。日常候选不会因大选刷新被抹去。
- 口谕和面谈上限8000字，朱批2000字。完整聊天保存，模型交谈上下文最多最近20轮、24000字；正文只带近期8次交谈摘要，避免长聊使每旬提示词无限增长。
- 奏折按自然段分别首行缩进两字，并留出段距；档案、分享图同步。新折记录真实在任官员的姓名、ID、当时职务和上奏/转奏身份，空衙门经在任官员转奏，无人时明确原折缺署名。旧档不补编原本未保存的官衔。

## 文件与兼容性

引擎改动集中于 `freedom/court/turn/events/edicts/foreign/harem/intents`，文本限额置于新 `core/text.js`。奏折记录、v17存档校验及新 `ui/memorial-document.js` 共同支持原始署名和逐段排版，UI、档案Canvas和提示词同步更新。

存档升v17，新署名和累计赏赐为可选字段，迁移时缺失字段分别表示历史未留或尚未使用。旧已结章节、旧待续预演、原骰和裁决完整保留；幂等提交、跨进度隔离、数值范围、只读保护及A1–A14仍保留。旧测试中明确期待已取消规则的断言改为对应的新行为，其余保护继续运行。新增v17完整预演哈希基线，历史v13及更早哈希保留。

DESIGN.md 已新增按玩家授权的v17规则，原正文中每槽一件事扩展为午间一次召见安排可含多人；大选规则扩展为保留大选并增设日常荐选。以上偏离来自玩家本轮对限制审计建议的明确采纳。
