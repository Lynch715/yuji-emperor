## 四类策略与统计口径

`scripts/simulate.mjs` 统一定义无为 / 乱批 / 尽职 / 贪心。四类均完整模拟 200 年，每种子 7,200 旬；饱和与标准差均取前 720 个已提交旬次，亡国率为亡国数 / 已结束在位期，未结束的末朝不计。无为另检查首次亡国不晚于第 540 旬。

- **无为（rest）**：只歇息；自动摄政、权臣、事件和结算照常发生。
- **乱批（random）**：沿奏报匣原顺序，沿用八分支；上朝三本、批折六本；各资源可负担的选项中均匀随机，累计扣支出且国库预留 8 万两。亡国率不设区间，只要求不低于同种子尽职。
- **尽职（diligent，默认）**：八分支及选项抽样与乱批相同，取件先急件、再按到期先后，完全相同时保留原序。亡国率记录为难度指标，减赋仍随机指定一州。
- **贪心（greedy）**：每旬上朝，急件优先、到期排序，前三本一律准奏；不能负担的议题不选，不改成驳回或借钱。摄政时转换为合法批折。亡国率仅参考；前 20 年任一民心 / 吏治 / 圣德 ≥95 的旬次比例仍须 <15%。此策略没有侍寝，不给它套用原随机策略的子嗣 4–9 条件。

尽职与乱批都硬查四项国势的前 20 年总体标准差 ≥5、200 年至少一次真实权臣代批且不每旬发生。三种主动策略都保留入寇 120–200、国库峰值 / 后期比例、事件 30–80 / 十年、年度现金守恒、粮储有限增长；四个固定种子不变。同等国力 400 场战役继续硬查 40%–60%。基线与施工后比较表见 `docs/ACCEPTANCE.md`。

## 数值与 DESIGN / 审计差异的理由

1. **C1**：正向国势效果在 80 / 90 处分段减半 / 四分之一；普遍民心 ×0.3，相关州奏报与单州项目只作用于该州。六部履职分沿用 `Σmax(0,政−贪墨/2)/150`，治理每月向 `50+履职分×5−管钱官侵耗×2` 回归 3%；皇威 / 圣德向 50 回归 2%、心情向 55 回归 5%，按审计要求执行。例行准奏只加治理 0.1；真实请赈才有救灾 / 圣德收益，拒赈圣德 −2，普通驳回不扣民心。
2. **C1 前置调参扩展**：原 DESIGN 的“积压 >12 本每旬治理 −1”在每旬 3–6 本来件、上朝上限三本的条件下长期压倒 3% 回归，改为每月治理 −1，仍保留逐本逾期和全部来件。治理 <45 时，足额付饷月的普遍民心效果为 `(治理−45)/30`；欠饷为 −3。移除原来高治理无事实自动加民心的正项。急件逾期民心效果统一−0.4，普通−0.03，逐本治理−0.08保留，再经普遍民心×0.3规则结算。
3. **C1 地方修复为本批额外校准**：在俸饷足额、没有国库旧欠、全国民心 ≥25 的月末，未叛乱州向 55 修复 **1.8%**，灾州仍扣 1；处在全面危机时不能靠这个规则自动脱困。这补上单州范围修正后的恢复渠道，不向全国直接加分。天灾当旬当地民心 −4，拨银救灾当地 +8，地方自筹当地 −3；均以实际灾情 / 处置为事实。数值偏离原表的理由是同时避免持续满值与持续负漂移。1.8% / 1.9% / 1.95% 全局系数的敏感性检查仍没有找到全部通过的组合，最终 1.8% 也未通过完整平衡，不能视作稳定定稿。
4. **C2**：严格采用季度 `Σpop×0.15×(1−灾情/100)`。军粮沿用兵力 / 22,000；每灾州另耗 2 万石 / 月。仓容为当前年耗三倍；按原文超额年霉变 10%，是软仓容，不把超额直接删除。balance 同时检查生产 / 霉变理论界与后50年峰值不超前50年 1.5 倍，峰值包含霉变之前的真实入仓。粮不足一月军粮时，当旬战力 ×0.7，不改永久军备。
5. **C3**：内帑月收入 3 万两，节俭把实际宫用乘 0.7。国库 / 内帑 / 粮不足的差额分别入债并落账，月结优先偿旧欠；季度进账后也偿旧欠。粮食用 `grainArrears` 单独计万石，不能把粮食差额与万两银债直接相加，这是对审计笼统“钱粮进 arrears”的单位修正。积欠不沿用余额的一百万上限，避免再次抹掉短缺。
6. **C4**：京营每月按 45,000 缺额的 1% 向上取整补员，饷银为每千人 1 万两；民心至少 30、存粮足一月军粮、国库可付款才补。征兵旧成本 / 工期保留，新项目只补所选军队 3,000 人；京营不超过 45,000。
7. **C5**：官职权重 `max(1,5−rank)`、能力取政 / 权谋均值，派系职位分除以 20 再加事件修正。事件修正为既有派系态度效果的四分之一、截在 ±30，月衰减 2%；任免、致仕、死亡与新局即重算。派系势力 >70 且皇威 <40，或任一合格在任官员 `野心×派系势力×(100−皇威)>150000` 可进入专权；地方权臣通过同派在京官员实际代批。真实代批每月最多一本、扣皇威 0.5，避免同旬多次调用连吞奏报；摄政 / 留守的明确指定代批不套此冷却。

9. **C7**：每年按长岁后的年龄使用 60+ 2%、70+ 6%、80+ 15% 死亡率。七十岁请求致仕一生一次，留任不每年重复生成同一请求；准予才退，病故清职位。科举按真实空缺取最多五人，无空缺零人，不再固定加三人；仍按三年一科和全局姓名去重。
10. **C8 / C9**：宫斗月事件频率沿用原 7%，只改发起者心机加权、最差关系目标、小产独立骰 `clamp(4%+(心机差)/2000,2%,8%)`。宴请按俭 / 常 / 盛 +2 / +4 / +7，同客距上次不到六旬减半。互市每季收入 `min(6,授权/2)`，一年四季，成功不立刻给钱；同国无论本次成败一年只议一次，交战停收。审计未定互市 X 的具体值，这个系数把反复即收现金改成持续经营收益。

低民心经济回归保留 108 组及原阈值。C1 后“全国 19、各州全 100”的旧样本违反加权定义，改为全国仍 19，一小州设 19 / 62 / 100、其余州按人口补足低民心；去掉官员野心以隔离自动代批救灾，真实无为策略仍保留权臣行为。旧 UI 序列化 fixture 同样隔离专权，以保留历史议题 ID；专权另有实际效果 / 冷却 / 地方委托回归，没有屏蔽游戏或 balance 中的权臣。
