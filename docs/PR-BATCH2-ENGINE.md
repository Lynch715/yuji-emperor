## 数值口径与 DESIGN 差异

- B1 沿用原月末 35% 事件概率，未混入其他批次的调频。季节系数为春 0.6 / 夏 0.4 / 秋 0.3 / 冬 0.5；每州权重严格为 `1+季节系数+pop/100`。原设计写季抽签，本批保留旧频率以限制范围，只修抽州与去重。
- B5 摄政的太后权谋取母妃心机；缺少相关人物资料时默认 65。经筵每次教养 +0.2，文采沿用原年增长上限；五才按 `aptitude×min(1,age/16)+education/10`。16 岁亲政和大婚为本次明确要求，替换旧版婴帝全额五才 / 立即配后宫行为。
- B7 税收政策默认持续四个征税季度，项目竣结后生效，保持“在途 → 兑现”的原流程；法定税率固定 0.8 / 1.2，普通效果包仍按执行度兑现。冷却六旬、封驳退款、截留 70% 是本次审计明确规则。
- B8 军力单位为有效兵力 / 500，使默认 35,000 人、60 军备对应 42 国力；同方向多个外邦取平均压力，避免重复算边境。背盟惩罚各 -5；每旬粮草 -6、国库 -4 沿用原成本，缺粮战力 ×0.7，天命对当旬战力作 ±38% 修正。将领军略以 50 为中性，亲征另受皇帝武略影响；胜负双方按对称伤亡和军备消长推进，六旬按真实战况收束。原设计未定这些战役细节，新增明确公式是为消除单由外邦 power 决定胜负的问题。
- 模拟策略为固定八分支：上朝仍最多三议题，专门批折最多六本（原本每三本一点精力）；随机选到受冷却 / 在途限制的旨意，轮转找同组合法备选；摄政上朝改批折、禁止任命。四种子使用同一策略，无按种子分支、无改阈值、无裁剪事件或重置失败王朝。与批次 1 的旧策略不能直接当同口径前后对照。
