# 《御极》美术规范 · 人物与场景

依据：提交 `093eaad`（main）。只规定美术资产本身和它们挂进界面的方式；不改数值、规则、提示词。界面令牌、字体沿用 `docs/UI-REDESIGN.md`（夜御案），本文不重复。

## 0. 总原则

1. **美术是增强层，不是依赖。** 任何一张图缺失、加载失败或离线，界面退回现在的样子（人名首字圆章、纯色章节头），游戏照常可玩。
2. **纸在案上。** 人物像、场景图都是"画在纸上的东西"，放在深色案面上；不做全屏铺底的原画风，不抢正文。
3. **画得简单，脸要分得开。** 用白描淡彩：线条干净、平涂淡色、不追求细节。省下来的工夫全部花在"每张脸一眼就和别人不同"上（§3.3）。
4. **人物像负责"是谁"，场景图负责"在哪"。** 场景图里不画可辨认的人物；朝代差异靠人物服饰体现，场景一套通用。
5. **历史人物有专属像**，其余人物从池里取，同池内不重复，用完才轮回。
6. 引擎、存档规则照旧：唯一的核心改动是 §3.4 的"脸号"字段，需升 `S.v` 并在 `migrate()` 补齐。
7. 游戏只加载 WebP。总量约 **377 张**，分三期出（§6），不在清单里的不出。

## 1. 画风：白描淡彩

| 项 | 规定 |
| --- | --- |
| 基调 | 中国白描淡彩：墨线勾形，平涂淡色。像一本好看的人物图谱，不像原画，不像海报 |
| 线 | 干净、粗细略有变化的墨线；衣纹只画主要几根 |
| 设色 | 平涂，最多一层浅浅的明暗；颜色降饱和：赭、朱、石青、石绿、米黄、墨灰 |
| 细节 | 服饰只画能认出朝代的大件（冠帽、领型、补子的位置、凤冠的轮廓），纹样用几笔示意，不画繁复刺绣、珠串 |
| 光与质感 | 无光影特效、无轮廓光、无发光；底子只有极淡的纸纹 |
| 与界面的关系 | 人物底色 `#E3D7BE`（即 `--paper-chip`）；夜景暗部接近 `--desk #1C1714`，光源用宫灯暖金 `--gold #C8A35A` |

**禁止**：模仿任何具体影视剧剧照或演员长相；模仿求仙途或其他游戏的美术；画中出现任何文字、印章、落款、水印；西式王冠、和服、韩服等错置服饰；奇幻元素。

## 3. 人物像

### 3.1 构图（所有人物像统一）

- **头肩像**：裁到肩下一点，服饰只露领口、肩、冠帽。
- 头顶距上边 10–14%，**双眼在 36–40% 高度**，脸部水平居中。这条决定圆形头像能不能裁准，必须严格。
- 四分之三侧面，朝左朝右各半；目光略偏，不直视观众。
- 纯色底 `#E3D7BE`；无道具、无背景、无边框。

### 3.2 取图顺序与角色分池

1. **专属像**：当前剧本中按姓名能在 `art-manifest.js` 查到专属像的，用专属像。
2. **池图**：否则按 `朝代 / 角色 / 档位` 找池，用脸号取图（§3.4）。
3. **首字圆章**：池还没出图，或角色不在下表，退回现在的样子。

| 角色 | 如何判定（读现有字段） | 档位 | 是否分朝代 |
| --- | --- | --- | --- |
| 皇帝 | `s.emperor` | 青 <40 · 老 ≥40 | 分 |
| 文官 | 官员，且不属下面两类；含未任职候补、地方巡抚 | 壮 <55 · 老 ≥55 | 分 |
| 武将 | 所任官职下标为 9（京营）或 25–28（四境总兵） | 一档 | 分 |
| 宦官 | 官职下标 8，且朝代为汉 / 唐 / 宋 / 明（清制内务府总管按文官） | 一档 | 分 |
| 后妃 | `harem.consorts` | 正位（皇后 / 皇贵妃 / 贵妃）· 常位（其余） | 分 |
| 秀女 | `harem.candidates` | 用后妃常位池 | — |
| 太后 | 太后 / 太皇太后 | 一档 | 只有明制有池；剧本太后都是专属像 |
| 皇子 / 公主 | `harem.children`，按 `gender` | 幼 0–6（共用）· 少 7–15 · 成 ≥16 | 幼童不分，少、成分 |
| 宗室女 | `harem.royalWomen` | 用公主成年池 | — |
| 士子 | 科举考生 | 青 <30 · 壮 ≥30，布衣儒巾 | 不分 |
| 外邦君主 | `foreign`，按 `frontier` | 北（草原）· 西（西域 / 高原）· 南（岭南 / 百越）· 东（海东） | 不分 |
| 女官等其他 | 官员 `gender` 不为「男」，或任何查不到池的人 | 首字圆章 | — |

朝代取 `s.scenario` 对应剧本的 `posts`（han / tang / song / ming / qing）；自定义开局「大晟」用明制。

### 3.3 脸要分得开（本规范的重点）

生成模型最容易犯的错是"所有人长一张脸"。每个池出图前，先在 `docs/ART-PROMPTS.md` 里给这个池的每张脸写一行**长相卡**，再按卡生成。

| 维度 | 可选项（举例） |
| --- | --- |
| 脸型 | 方、长、圆、瘦削、宽颧、尖下巴 |
| 胡须（男） | 无须、短髭、八字、三绺长髯、络腮、山羊须、花白稀疏 |
| 眉眼 | 浓眉、细眉、八字眉；大眼、细长眼、垂眼、吊梢眼、眼袋重 |
| 鼻口 | 高鼻、宽鼻、塌鼻；薄唇、厚唇、紧抿、微张 |
| 体态 | 清瘦、富态、魁梧、佝偻 |
| 肤色 | 白皙、偏黄、黝黑、风霜 |
| 标记 | 痣、深法令纹、额纹、旧疤（武将）、酒糟鼻、斑白鬓角 |
| 神情 | 沉稳、刚直、圆滑、阴沉、温厚、倨傲、疲惫、紧张 |

规则：

- **同池任意两张脸，至少有 4 个维度不同**，其中脸型或胡须必须不同（女性用发际线、发髻高低替代胡须）。
- 有剧本资料的历史人物，长相卡按剧本里的性格、秘密和史书记载写（如李广魁梧善射、汲黯直谏倨傲），不靠模型自由发挥。
- 验收时把同池全部缩到 44px 圆形排成一行，任何两张"一眼像同一个人"就重出其中一张。

### 3.4 脸号：同池内不重复

- 每类人物在创建时拿一个**脸号** `faceNo`，按类别顺序递增（文官、武将、宦官共用官员计数器）。脸号只决定"谁先挑脸"，不直接等于图号。
- **界面按脸号顺序避让取图**（`src/ui` 内的纯函数，可在 Node 里测）：对每个池，把当前归入该池的人（**含已故者**，按其最后年龄与官职归池）按 `faceNo` 从小到大排，依次取该池中第一张还没被占的脸。
  - 已故者照样占着自己的脸，所以有人去世不会让别人换脸；只有在世者跨档位或改任武职 / 宦职时，同池里脸号比他大的人才可能顺移，这种情况很少。
  - 池里的脸用完后，新来的人优先复用"占用者全部已故"的脸；仍没有空，才取 `faceNo % 池脸数`。
- 引擎只管发号，不知道美术池多大：在 `src/core` 加纯函数 `assignFaces(state)`，对缺 `faceNo` 的皇帝、官员、后妃、候选人、皇嗣、宗室女、外邦君主补号；在 `migrate()` 和每次 `commitTurn` 末尾调用。计数器存 `s.faceCounters`。升 `S.v`，老存档按数组顺序补号。
- 跨档位换脸（文官过 55 岁、后妃升正位、皇嗣成年）时，按同一个 `faceNo` 去新池取图，所以是另一张脸。这样不用为同一个人画多档，算作"人老了、身份变了"，可以接受。
- 科举考生不进存档名册，用 `candidate.id` 的哈希取脸；及第入仕后按官员发新号。

### 3.5 专属像（历史人物）

- 七个剧本里的每位开局人物都有专属像：皇帝、`officials`、`consorts`、`children`、`foreign` 君主、`dowager`，共 142 人。
- 七位开局皇帝各加一张老年像（≥40 岁时切换）；开局时未成年的皇嗣（李承乾、李泰、李恪、弘历、福惠）各加一张成年像。合计 **154 张**。
- 文件按剧本和数组下标命名，`art-manifest.js` 里写姓名 → 文件，取图时按"当前剧本 + 姓名"查。
- 可以参考该人物现存的历代画像来定长相（如明清帝王像），但画风统一成白描淡彩，不临摹原画。

## 4. 场景图

### 4.1 通则

- 同样白描淡彩：建筑用墨线勾，平涂淡色，不画复杂光影；夜景整体压暗，只留灯火的暖金。
- 画空间，不画人；最多远景小剪影（不可辨认、不分朝代）。
- 建筑走"通用宫制"：红墙、木构、斗拱、宫灯、屏风、书案，不复刻真实殿宇，不出现匾额文字。
- **主要内容放在中间水平带（上下 30–70%）**：章节头会裁成 4:1 细条，只保留这一带。

### 4.2 清单

只有御案和寝殿出夜景，其余一张图日夜通用（夜间时辰在 CSS 里压暗 15%）。

| 键 | 内容 | 对应行动 / 用途 |
| --- | --- | --- |
| `desk-day` | 御案：案、笔架、奏折摞、镇纸，窗外宫墙 | 默认（朝、午）；歇息、空槽、批折、下旨 |
| `desk-night` | 同上，烛下 | 默认（夜） |
| `court` | 大殿朝会，御座远景，丹陛，两班位次（剪影） | 上朝、外交、朝堂殿阁 |
| `audience` | 偏殿召对，屏风、坐墩 | 召见、面谈、任命 |
| `banquet` | 殿内宴席，几案、酒器、灯 | 宴请 |
| `palace` | 后宫寝殿外廊，灯笼、帘幕（不画床榻），夜 | 后宫（夜） |
| `garden` | 御花园，曲桥、假山、亭 | 后宫（午）、选妃、后宫殿阁、自拟情节「园 / 花 / 亭」 |
| `study` | 书斋：书架、经卷、香炉 | 私下行事、经筵、格物 |
| `exam` | 殿试考场，成排考案 | 科举 |

| `camp` | 军营大帐、旌旗、营火（无战斗、无伤亡） | 亲征 |

| `ending` | 雪夜空殿、闭合的史册 | 驾崩 / 封卷 |

### 4.3 殿阁题图

由场景图裁 3:1：朝堂 ← `court`，后宫 ← `garden`，宗室 ← `accession`，格物 ← `study`，科举 ← `exam`。另画 3 张 3:1 日景：`hall-realm`（天下、国势全览共用，青绿山河长卷）、`hall-treasury`（库门、钱箱、粮仓）、`hall-archive`（书架长廊）。

场景 13 张 + 殿阁 3 张 = **16 张**。

## 5. 挂进界面

| 位置 | 尺寸（桌面 / 手机） | 做法 |
| --- | --- | --- |
| 名册、列表头像 `.portrait` | 44px 圆形（不变） | `<img>` 填满，`object-fit: cover; object-position: 50% 32%`；失败时显示原首字 |
| 朝堂 / 后宫 / 宗室 人物卡 | 64×80 圆角 6px | 同一张图，`object-position: 50% 25%` |
| 召见 / 面谈 纸面 | 200×250 / 120×150 | 完整人像，纸面左上 |
| 奏折上奏人 | 28px 圆形 | 跟在姓名前 |
| 正文章节头 | 全宽 × 120px / 96px | 场景图裁 4:1，底部 40% 渐变到 `--paper`，章节标题在纸上，不压在图上 |
| 行动浮层头图 | 全宽 × 160px / 112px | 同上，渐变到 `--desk-shade` |
| 殿阁题图 | 全宽 × 180px / 120px | 渐变到 `--desk`，标题在渐变以下 |

- 文字一律不直接压在图上；对比度要求（≥ 4.5:1）照旧。
- 图片 `alt=""` + `aria-hidden`（姓名就在旁边），`loading="lazy"`，`decoding="async"`，写明宽高防止布局跳动。
- 手机 360px 宽无横向滚动；场景用 720 档（`srcset`）。
- 设置里加「显示插图」开关（只存本机，不进存档）；关闭后全部退回无图界面。

## 7. 生成方法（内置 imagegen，求快）

1. **先出定调样张**：明制文官（壮）、明制后妃（常位）、`desk-night`、`court` 各一张。四张定稿后作为参照图，随后每次生成都传入，保证画风一致。这四张本身在清单里。
2. **池图按 2×2 一组出**：一次生成四张不同的脸（同池、同档位），每格按 §3.1 构图，格间留 `#E3D7BE` 空隙。导出时切成四张。四张的长相卡写进同一条提示词。
3. **专属像单张出**：长相卡来自剧本资料（§3.3）。
4. 每池出完拼一张 44px 对照条，查撞脸、查眼高线；不合格的单独重出。
5. 导出只做裁切、等比缩放、转 WebP，不做修图。
6. 所有实际使用的提示词与长相卡记录到 `docs/ART-PROMPTS.md`，格式同 `docs/APP-ICON.md`。

### 7.1 提示词骨架

人物（2×2 一组）：

```text
Use case: game character portraits. A 2x2 grid of four DIFFERENT people, each in its own cell separated by plain #E3D7BE gaps. Chinese baimiao line drawing with light flat color washes: clean ink outlines, flat muted colors (ochre, cinnabar, azurite, malachite, beige, ink gray), minimal shading, simple costume with only the key period features, no intricate embroidery or jewelry.
All four: {dynasty}-dynasty {role}, {age band}, wearing {costume cues from §3.6}. Head-and-shoulders, three-quarter view (cells 1 and 4 face left, cells 2 and 3 face right), gaze slightly off-camera. In every cell the top of the head is 12% from the cell's top edge and the eyes sit at 38% of the cell's height, face centered. Plain #E3D7BE background, faint paper grain.
Cell 1: {face card 1}. Cell 2: {face card 2}. Cell 3: {face card 3}. Cell 4: {face card 4}.
The four faces must look clearly like four unrelated individuals: different face shapes, facial hair, brows, eyes, builds and expressions.
Avoid: any text, seals, signatures, watermark, borders; anime, 3D render, photography, glow; resemblance to any real actor or TV drama still; non-Chinese court dress.
1024x1280.
```

人物（单张专属像）：同上，改为单人、整幅一格，`Subject: {姓名对应的长相卡}`，不写姓名。

场景：

```text
Use case: game background illustration. Chinese court {location from §4.2} drawn in simple baimiao line art with light flat color washes on pale paper, muted palette, minimal shading.
Time: {daytime: pale even light | night: overall very dark, close to #1C1714, lit only by a few warm palace lanterns or candles}.
No people, or only tiny indistinct silhouettes far away. Generic palace architecture, not a real building. Keep the important elements in the horizontal middle band (30–70% of height).
```

## 8. 内容边界

- 后宫题材只表现身份与仪态：衣着端庄完整，不画床笫、沐浴、半裸或挑逗姿态；`palace` 场景不出现床榻。
- 皇子、公主、幼年皇帝按真实儿童样貌画，服饰得体，不做成人化处理。
- 亲征、边患只画营帐、旌旗、烽燧，不画战斗、伤亡、血。
- 外邦人物只取服饰大意，不夸张面貌、不丑化。

## 9. 验收

- 每池 44px 对照条存 `qa/art/`：无撞脸、眼高线一致、底色一致。
- 清单核对：`art-manifest.js` 引用的文件与 `assets/art/` 实际文件一一对应，每期张数与 §6 一致；七个剧本的开局人物都能取到专属像。
- `node --test`：`assignFaces` 的确定性（同种子同结果）；老存档迁移后每人都有 `faceNo`；同类别前 N 人不撞脸（N = 池脸数）；大晟开局 25 名官员无重复脸。
- 浏览器：1280 / 768 / 390 三档截图存 `qa/art-*.png`；Pages 发布后线上能取到图；断网或删去 `assets/art/` 后界面退回首字圆章与纯色章节头且无报错；关闭「显示插图」同样生效。
- 体积：单张不超 §2 预算；首屏新增请求 ≤ 6 张；`assets/art/` 全部完成 ≤ 12 MB；Lighthouse 可访问性仍 ≥ 95。
- 对比度：所有叠在渐变上的文字 ≥ 4.5:1（≥ 24px 文字 ≥ 3:1）。
- 不修改 `src/core` 中 `assignFaces` 与 `migrate` 补号以外的任何逻辑；`npm test` 全过，200 年无模型模拟照常跑通。
