## 奏折完整流程

沿用DESIGN中的事务规则：拟批先入本旬日程，起驾时统一结算。批折窗口不提前扣钱粮，因此起驾之前仍允许明确改批。

独立浏览器实走如下：

1. 第一折准奏入朝间日程，列表待批立即从6降为5，另列已拟批1。
2. 再点此折只显示原拟批与“编辑朝间拟批”，没有准奏 / 驳回radio；明确编辑后原决定、朱批、时辰均保留。
3. 点新批折自动使用空午间，默认队列排除朝间那一本；选折列表禁用朝间已占用的折子。
4. 余下5折拟批后，待批为0、已拟批为6，新批折入口不可用；仍可从原日程明确改批或撤下。
5. 起驾后旧ID `routine-0-0/1/2`、`routine-1-0/1/2` 全部不再存在于奏报匣；新队列是 `routine-2-0…4`，标明“本旬新呈”。没有重复应用旧效果包。

新增10条回归覆盖读取旧日程、计数、跨时辰排除、重复 / 过期ID拒绝、明确改批、撤下释放、列表状态、准驳结案与提交幂等、未结案选项以及新旧呈折区分。**154通过，0失败、0跳过**。既有七种同种子决定和完整预演的对照继续通过，其他行动的原序列化代码也保持一致。
