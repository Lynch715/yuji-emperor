# 奏报分层验收 · 2026-11-05

玩家反馈御前待批尽是借书、修瓦、灯油等小事。本轮把权限和取舍作为呈折门槛，开发在 `codex/memorial-hierarchy`，等待玩家测试。

## 最终行为

- 御前亲裁：22种制度与国势议题，显示为什么需要皇帝定夺；每种方案有独立代价。新局最多3本，平稳时每3旬最多2本，未结的例行大政最多6本；普通折期限6旬。灾情、缺粮、积欠、边患、军需等依实际国势优先，急折期限3旬，紧要事项可以越过平稳队列上限。事件、战役、科举与格物原有专折继续呈递。
- 例行奏报：钱粮、粮储、地方与边防，引用报告时的实际国势，仅供备览。
- 有司细务：小修、借书、灯油、日常纠纷和案牍驿递，照原例办理，不逐件请旨。原有常用开支照旧按月结算，阅读常报不增减钱粮或好感。
- 每3旬有2条常报及1条细务；最近72条在奏报匣中，已提交章节保留本旬新常报并随旧卷封存，完整JSON及起居注导出保留。
- 平稳旬没有新御前折时，只请求正文；新御前折仍复用并行奏文请求、失败模板回退和单折补写，不增加新的请求类型。真实模型文风留给玩家测试，本轮浏览器使用离线试读。

## 存档与历史基线

存档升v23，新增只读`briefings`。v22及更早存档补空数组；已收到的小折不被擅自撤去，原文、选项、截止旬与已拟批日程都保留，处理完后由新规则接替。旧待续不重算、不重掷，正式提交时才补结构，重复提交仍只结算一次。数据库名称、版本与槽位标识未变。

阶段9固定样例显式使用v22旧模板路径；七条历史预演的SHA256仍与原v17基线一致，没有更新预期哈希。旧95题覆盖测试继续针对旧生成器运行，当前生成器另有12项回归。原有数量、积压、风格与并行请求测试改用明确的积压样例或月首样例，避免假定每旬必有3–6本新折。构建文件约815KB，预算由810KB调整为830KB，图标预算不变，未增加框架或构建依赖。

## 验收结果

- `npm test`：584项全部通过，含12项新增分层回归。
- `node scripts/simulate.mjs 200 '御前分级两百年'`：7200旬、200年完成；状态断言、事务提交通过，4次自然驾崩、0次亡国、1141件事件。国库峰值2601.22万两、粮储峰值1492.24万石，既有饱和指标为0。这是单种子尽职策略的稳定性检验，不据此声称所有策略平衡已完成。
- 应用内浏览器，独立 `127.0.0.1:58138` 来源，仅使用新建试读进度：1280×900与360×800均无横向溢出，手机常报展开目标约46px。
- 实走御前亲裁选项→入日程→起驾→结案；中间平稳旬不强行添折，月首新增2本亲裁事项、2条常报和1条细务；常报不进入待批数量，手机可展开阅读，刷新后进度保持，起居注可查看本旬常报。浏览器控制台无警告或错误，桌面与纸面文字颜色分别核验。
