# 奏折的实际取舍与朱批显示

原先95个题目的标签不同，常规选项却共用国库−2万两、吏治+0.1的效果包，第三本还统一追加0.6万石役粮。玩家很难从具体事情判断该选哪项。本次按用户追加要求替换这些统一效果。

## 政策

`src/core/memorial-choices.js`集中列出95个题目及灾情请赈的政策。通常两项；税册与赈灾三项，另可留中、发部议。没有通用效果兜底：缺少题目配置会报错，覆盖测试逐一检查95题。

|事情|方案及实际变化（未触及高值收益递减时）|
|---|---|
|重复税款|清退：国库−1.2万、当地民心+1；核票：−0.4万、吏治+0.4、当地民心−0.2；催旧册：+2.4万、当地民心−1.2、圣德−0.3|
|军营休假|轮休：当地民心+0.8、圣德+0.2、战备−0.8；等换防：粮储−0.2万石、战备+0.5、当地民心−0.5|
|使臣饮食|加设礼遇：内帑−1.5万、对应外邦态度+1.2；循旧例：皇威+0.3、态度−0.6|
|灾情请赈|拨银：国库−8万、灾情−5；开仓：−1万、粮储−4万石、灾情−4；募赈：−0.3万、灾情−1、承办官好感−1，各有不同民心与君德变化|

人物、军队与外邦目标在呈折时绑定存档已有ID。军务优先当前战区，其次边患最高的边军；礼遇选择未交战外邦，选项显示具体名称。效果经过`applyEffects`计算、边界截断及现有收益递减，实际变化写入账目。尚未选择的方案只供模型理解待议取舍，不能写成已办。

新政策的第二项仍复用`reject` ID，但它可能是轮休、开仓等具体办法，不能额外触发旧的当廷驳回皇威+2。无后果说明的旧折仍保留原奖励。旧常规准奏、旧当廷驳回另有兼容测试。

国库、内帑、仓粮逐项检查：界面余额不足禁选，核心在执行前再次拒绝，不能先扣一部分再报错。不同折子合计超支同样由事务预演拒绝。廷议票拟考虑当地民心、战备与边患，不只看选项名字。

## 存档与显示

版本升v13。新选项带可选`consequence`及军队、外邦效果包，实际状态使用原有字段。迁移不重建已收折子或旧待续；续写、提交幂等与随机数规则不变。因新效果暴露的极小小数变化统一将账目负零转为零，实际状态数值不变，JSON存档往返保持相等。

朱批从40px减到34px，按内容及窗口宽度自动增高，仍最多100字。选项显示具体说明、小数变化，灾情与边患下降显示为有利变化。

## 验证与设计调整

- 新增7项测试，覆盖95题差异、相反政策的实际钱粮 / 民心、学校与军营方案、三种赈灾与不足粮的原子拒绝、礼遇的内帑 / 邦交、v12旧选项 / 待续保留、提交幂等、无隐藏驳回奖励及负零往返。
- 全套370项通过；200年、7,200旬无模型模拟完成，最大粮储240万石。另保留30年先急件准奏模拟、50年题材覆盖与全部旧断言 / 改写测试。
- 原“30年粮储始终不超当前仓容1.2倍”是统一役粮费用下的采样预期，并非设计硬上限。新政策按具体事情消耗粮储，仓容又随军队和灾情变化；改为核对只有季度新粮增加库存、库存非负且有限，以及按历史最高仓容、年产粮和30%超仓损耗推导的收支上界。季度产粮、连灾减产与年霉变30%的精确断言保留。
- 七路径预演按新政策有意变化，新增v13完整哈希，保留v12与更早记录。单文件约546KB，预算由520KB调到550KB，图标60KB预算不变；未引入依赖。
- 应用内浏览器：本地空卷试读，360px与1280px无横向滚动；百字朱批34px、内容高与可见高均635px，刷新恢复完整；实际执行错时放行后起居注显示国库−0.5万、吏治+0.2、当地民心+0.5。控制台无警告或错误。未调用付费模型API，未使用实体手机。
