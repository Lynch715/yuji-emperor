# 御极 · 皇帝模拟器

[开始游戏](https://lynch715.github.io/yuji-emperor/) · [源码仓库](https://github.com/Lynch715/yuji-emperor)

本地可运行的单文件帝王文字经营游戏。设计源为 [DESIGN.md](DESIGN.md)，源码分模块放在 `src/`，`index.html` 是可直接放到 GitHub Pages 的构建产物。运行不需要安装依赖，不含统计服务或预置密钥。「夜御案」界面按规格通过 Google Fonts 加载字体；离线或加载失败时使用系统字体，游戏仍可用，没有外部运行脚本。

## 开始

需要 Node.js 22 或更新版本（本次使用 Node.js 25.9.0）。

```sh
npm run build
npm run serve
```

打开 http://127.0.0.1:4173 。选择“登基开局”，可直接选择试读；正式模型叙事在“设置”中配置服务商、地域、模型与自己的密钥。API 地址须支持浏览器 CORS；服务商依据见 [docs/API.md](docs/API.md)。

每旬安排朝、午、夜三个时段，再点“起驾 / 歇息”。上朝、批折、圣旨、任命、面谈、宴请、内廷、外交、出巡、亲征与私下行事有不同时间和精力要求。六殿提供人物、州郡、钱粮、皇嗣和历史记录。手机底部四键打开抽屉。

## 存档与故障恢复

- 三个独立存档位；IndexedDB 保存主档，localStorage 留恢复副本。当前使用存档结构 v4，兼容本项目早期 v1/v2/v3。
- 读档损坏、来源不可读、并发修改或无法解释的副本分歧，进入只读保护，不覆盖原数据；存档阁可导出原始副本。
- 预演先保存，再请求叙事。请求失败、刷新与重试沿用同一结算和骰子。“先记入起居注”可落下已发生的结果。
- 每旬共享最多 4 次请求、240 秒，包括分类、面谈、网络和格式重试。预算用完后可按结算表完成，不通过重掷换运气。
- 导入写入空卷；重用已有卷位时，先封存完整旧卷，封存失败即停止替换。旧卷可在存档阁导出，再导入空卷恢复。
- 主档或恢复副本单独写入失败会提示导出。恢复副本连续因配额不足而落后时，以可追溯的较新主档为准；真正分叉仍锁定。
- JSON 存档和全本 Markdown 导出不含 API 密钥。密钥默认仅留当前内存；勾选“在本机记住密钥”才保存于此浏览器。

## 检查

```sh
npm test
npm run simulate
npm run balance
```

`npm run balance` 固定运行四个预先声明的种子，每个 200 年，按国库峰值与前后 50 年峰值比、每个十年事件、完整在位期子嗣均值和 10%–35% 亡国率验收；同时验证纯歇息 15 年内亡国与 108 组低民心三年现金约束。驾崩通过 succession 继续原王朝，只有亡国才另启国家。

`npm test` 使用 Node 原生测试，包含 200 年随机策略模拟、50 年家庭模拟及 100 旬历史/存档往返。独立模拟可指定年数和种子：

```sh
node scripts/simulate.mjs 200 自定种子
```

模拟中丢弃无模型的空白章节以减少无意义的归档开销，数值、事件、结算和幂等凭据全部保留；章节保存和归卷另有真实 100 旬测试。模拟摘要是特定种子的样本，不能当作玩家总体结局概率。

本次完整验收范围、截图及尚未验证的部分见 [docs/ACCEPTANCE.md](docs/ACCEPTANCE.md)。

## 工程

- `src/core/`：随机数、状态与迁移、效果包、岁时结算、朝局、后宫、外交、事件、宏愿、史册和事务；经济规则包含民心停减税、超预算冗费、低民心应急支出与可追溯积欠。
- `src/llm/`：兼容流式接口、提示词、JSON 修复、叙事约束和流式正文提取。
- `src/store/`：带校验、版本追溯和并发比较写入的存档及旧卷封存。
- `src/ui/`：中文御案界面、行动面板、六殿、设置与移动抽屉。
- `scripts/build.mjs`：零依赖拼接器；生成内联 CSS/JS 的 `index.html`。
- 本机参考源码与历史调试 / 验收文件不随公开仓库发布；仓库保留运行测试必需的固定种子材料。

推送 main 后，GitHub Actions 先运行全部测试，再构建并发布 Pages；站点产物仅含单文件游戏，不包含源码、参考文件、调试存档或接口密钥。

历史验收文档中的部分 qa 链接仅对应本机留档；本次公开发布结果见 [发布记录](docs/RELEASE.md)。
